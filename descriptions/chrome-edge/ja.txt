🧩 TagSpaces Web Clipper — ウェブコンテンツを保存・タグ付け・管理

あらゆるウェブページをキャプチャして、デバイスに直接保存できます — クラウド不要、アカウント不要、トラッキング不要。TagSpaces Web Clipperはプライバシーファーストのウェブスクレイパーで、何を保存するか、どのように保存するかを完全にコントロールできます。

🔒 完全プライベート — 登録不要

サインアップ不要。サーバー不要。データ収集なし。すべてがコンピュータにローカル保存されます。クリップしたファイルはあなたのものです。

⭐ 主な機能

📝 MarkdownまたはHTMLで保存 — 画像を埋め込んだまま、TagSpaces、Obsidian、Notion、またはこれらのオープン形式をサポートする任意のアプリで編集・注釈が可能。
📄 MHTMLで保存 — ページのレイアウトと書式をそのまま保持し、任意のブラウザや対応リーダーで開くことができます。
✂️ 選択したコンテンツをクリップ — ページの必要な部分だけを保存。
📸 フルページスクリーンショット — ページ全体をPNG画像としてキャプチャ。
🔖 ビジュアルブックマーク — URLをプレビュー画像と共に保存して、お気に入りサイトのビジュアルコレクションを作成。
📍 GPSおよびPlusコード抽出 — 地図URLから位置データを抽出し、TagSpacesのMapiqueビューで活用。
🏷️ 保存時にタグ付け — クリップ時にタグを追加して、ファイルを即座に整理し、後で簡単に見つけられます。

保存されたすべてのファイルは標準的なオープン形式 — ベンダーロックインなし。TagSpaces、お気に入りのテキストエディター、またはHTML、Markdown、MHTML、PDF、PNGをサポートする任意のツールで利用できます。

💻 TagSpacesエコシステムの一部

TagSpaces Web Clipperは、TagSpacesデスクトップアプリとシームレスに連携します — 無料のオフラインファーストな個人知識管理ツール兼ファイルマネージャーです。TagSpacesを使えば、サーバーにデータを送ることなく、タグ、色、メタデータを使ってデバイス上のあらゆるファイルを整理できます。

TagSpacesでできること:
🗂️ あらゆるファイルタイプにタグと色を付ける — ドキュメント、画像、ノート、ウェブクリップ
📝 MarkdownまたはリッチテキストでノートをAir作成・編集し、自分が所有するシンプルなファイルとして保存
🌍 内蔵のMapiqueビューでインタラクティブマップ上にジオタグコンテンツを表示
🔍 強力なフィルターでローカルファイルコレクション全体を検索・閲覧
📁 フォルダ、ドライブ、接続された場所をまたいで作業 — 完全オフライン

TagSpacesはオープンソースで、Windows、macOS、Linux向けに無料で提供されており、パワーユーザー向けのオプションのPro機能もあります。
