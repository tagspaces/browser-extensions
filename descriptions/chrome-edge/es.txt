🧩 TagSpaces Web Clipper — Guarda, etiqueta y controla tu contenido web

Captura cualquier página web y guárdala directamente en tu dispositivo — sin nube, sin cuenta, sin rastreo. TagSpaces Web Clipper es un capturador web centrado en la privacidad que te da el control total sobre lo que guardas y cómo lo guardas.

🔒 100% Privado — Sin registro requerido

Sin registro. Sin servidores. Sin recopilación de datos. Todo se guarda localmente en tu computadora. Tus recortes te pertenecen.

⭐ Características principales

📝 Guardar como Markdown o HTML — con imágenes integradas, listo para editar o anotar en TagSpaces, Obsidian, Notion o cualquier aplicación que soporte estos formatos abiertos.
📄 Guardar como MHTML — conserva el diseño y formato completo de la página tal como lo ves; ábrelo en cualquier navegador o lector compatible.
✂️ Recortar contenido seleccionado — guarda solo las partes de una página que te interesan.
📸 Capturas de pantalla de página completa — captura páginas enteras como imágenes PNG.
🔖 Marcadores visuales — guarda una URL con imagen de vista previa para crear una colección visual de tus sitios favoritos.
📍 Extracción de GPS y Plus Codes — extrae datos de ubicación de URLs de mapas para usar en la vista Mapique de TagSpaces.
🏷️ Etiquetar al guardar — añade etiquetas al recortar para organizar tus archivos al instante y encontrarlos fácilmente después.

Todos los archivos guardados son formatos estándar y abiertos — sin dependencias. Úsalos con TagSpaces, tu editor de texto favorito o cualquier herramienta que soporte HTML, Markdown, MHTML, PDF o PNG.

💻 Parte del ecosistema TagSpaces

TagSpaces Web Clipper funciona a la perfección con la aplicación de escritorio TagSpaces — una herramienta gratuita de gestión de conocimiento personal y gestor de archivos sin conexión. TagSpaces te permite organizar cualquier archivo en tu dispositivo usando etiquetas, colores y metadatos, sin enviar nunca tus datos a un servidor.

Con TagSpaces puedes:
🗂️ Etiquetar y colorear cualquier tipo de archivo — documentos, imágenes, notas, recortes web
📝 Crear y editar notas en Markdown o texto enriquecido, guardadas como archivos simples que te pertenecen
🌍 Visualizar contenido geoetiquetado en un mapa interactivo con la vista Mapique integrada
🔍 Buscar y explorar toda tu colección de archivos locales con potentes filtros
📁 Trabajar entre carpetas, unidades y ubicaciones conectadas — todo sin conexión

TagSpaces es de código abierto y está disponible gratuitamente para Windows, macOS y Linux, con funciones Pro opcionales para usuarios avanzados.
