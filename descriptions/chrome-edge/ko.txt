⭐ 주요 기능

📝 Markdown 또는 HTML로 저장 — 이미지가 포함되어 TagSpaces, Obsidian, Notion 또는 이 오픈 형식을 지원하는 모든 앱에서 편집하거나 주석을 달 수 있습니다.
📄 MHTML로 저장 — 페이지의 전체 레이아웃과 서식을 그대로 보존하고 모든 브라우저나 호환 리더에서 열 수 있습니다.
✂️ 선택한 콘텐츠 클리핑 — 페이지에서 필요한 부분만 저장합니다.
📸 전체 페이지 스크린샷 — 전체 페이지를 PNG 이미지로 캡처합니다.
🔖 비주얼 북마크 — 미리보기 이미지와 함께 URL을 저장하여 즐겨찾는 사이트의 시각적 컬렉션을 만들어보세요.
📍 GPS 및 Plus Code 추출 — 지도 URL에서 위치 데이터를 추출하여 TagSpaces의 Mapique 뷰에서 활용합니다.
🏷️ 저장 시 태그 추가 — 클리핑할 때 태그를 추가하여 파일을 즉시 정리하고 나중에 쉽게 찾을 수 있습니다.

저장된 모든 파일은 표준 오픈 형식으로 — 종속성이 없습니다. TagSpaces, 즐겨 사용하는 텍스트 편집기, 또는 HTML, Markdown, MHTML, PDF, PNG를 지원하는 모든 도구에서 사용할 수 있습니다.

TagSpaces Web Clipper는 TagSpaces 데스크톱 앱과 완벽하게 연동됩니다 — 무료, 오프라인 우선의 개인 지식 관리 도구이자 파일 관리자입니다. TagSpaces를 사용하면 서버에 데이터를 전송하지 않고도 태그, 색상, 메타데이터를 사용하여 기기의 모든 파일을 정리할 수 있습니다.

📝 Markdown 또는 서식 있는 텍스트로 노트 생성 및 편집, 본인 소유의 일반 파일로 저장
