🧩 TagSpaces Web Clipper — Enregistrez, étiquetez et maîtrisez votre contenu web

Capturez n'importe quelle page web et enregistrez-la directement sur votre appareil — sans cloud, sans compte, sans traçage. TagSpaces Web Clipper est un outil de capture web axé sur la confidentialité qui vous donne le contrôle total sur ce que vous enregistrez et comment vous le faites.

🔒 100% Privé — Aucune inscription requise

Pas d'inscription. Pas de serveurs. Pas de collecte de données. Tout est enregistré localement sur votre ordinateur. Vos captures vous appartiennent.

⭐ Fonctionnalités clés

📝 Enregistrer en Markdown ou HTML — avec images intégrées, prêt à être modifié ou annoté dans TagSpaces, Obsidian, Notion ou toute application prenant en charge ces formats ouverts.
📄 Enregistrer en MHTML — préservez la mise en page et la mise en forme complètes de la page telles que vous les voyez ; ouvrez-les dans n'importe quel navigateur ou lecteur compatible.
✂️ Capturer le contenu sélectionné — enregistrez uniquement les parties d'une page qui vous intéressent.
📸 Captures d'écran pleine page — capturez des pages entières sous forme d'images PNG.
🔖 Favoris visuels — enregistrez une URL avec une image d'aperçu pour constituer une belle collection de vos sites préférés.
📍 Extraction GPS et Plus Codes — extrayez des données de localisation depuis les URLs de cartes pour les utiliser dans la vue Mapique de TagSpaces.
🏷️ Étiqueter lors de l'enregistrement — ajoutez des étiquettes lors de la capture pour organiser instantanément vos fichiers et les retrouver facilement.

Tous les fichiers enregistrés sont dans des formats standard et ouverts — sans dépendance. Utilisez-les avec TagSpaces, votre éditeur de texte préféré ou tout outil prenant en charge HTML, Markdown, MHTML, PDF ou PNG.

💻 Partie de l'écosystème TagSpaces

TagSpaces Web Clipper fonctionne parfaitement avec l'application de bureau TagSpaces — un outil gratuit de gestion des connaissances personnelles et gestionnaire de fichiers hors ligne. TagSpaces vous permet d'organiser n'importe quel fichier sur votre appareil grâce aux étiquettes, couleurs et métadonnées, sans jamais envoyer vos données à un serveur.

Avec TagSpaces vous pouvez :
🗂️ Étiqueter et colorier tout type de fichier — documents, images, notes, captures web
📝 Créer et modifier des notes en Markdown ou texte enrichi, stockées comme de simples fichiers vous appartenant
🌍 Visualiser le contenu géolocalisé sur une carte interactive avec la vue Mapique intégrée
🔍 Rechercher et parcourir toute votre collection de fichiers locaux avec des filtres puissants
📁 Travailler entre dossiers, lecteurs et emplacements connectés — entièrement hors ligne

TagSpaces est open source et disponible gratuitement pour Windows, macOS et Linux, avec des fonctionnalités Pro optionnelles pour les utilisateurs avancés.
